# 网站维护说明

你的个人网页有四个部分：Bio、CV、Publication、Working Paper。网页正文来自 `content/` 中的纯文字 Markdown 文件，不需要编辑网页代码。

## 直接修改文字

| 想修改什么 | 打开哪个文件 |
| --- | --- |
| Bio 正文 | `content/_index.md` |
| CV 网页正文 | `content/cv/_index.md` |
| 已发表论文 | `content/publication/_index.md` |
| 工作论文和进行中的研究 | `content/working-paper/_index.md` |
| 姓名、中文名、学校、身份、邮箱 | `data/profile.yaml` |
| 网站域名 | `hugo.yaml` 中的 `baseURL`；还需同步 GitHub Pages 与 Cloudflare 设置 |

每个 Markdown 文件开头两条 `---` 之间是标题和简介设置；下方就是网页正文。直接改正文、保存即可。用 VS Code、TextEdit 的纯文本模式或其他文字编辑器打开；不要保存成 Word 或富文本 RTF 格式。

```markdown
这是一个普通段落。另起一段时，空一行。

## 这是二级标题

### 这是论文标题

**加粗文字**，*斜体期刊名*。

[文章链接](https://doi.org/你的DOI)
```

## 本地修改与预览

在 Finder 中双击根目录的 `预览网站.command`，然后打开 `http://localhost:1313/`。也可以在该文件夹的终端运行 `sh scripts/preview.sh`。

预览运行期间，修改 `content/` 中的文字并保存，浏览器会自动刷新。预览只在自己的电脑可见。关闭预览终端或按 Control+C 可以停止预览。

首次搭建已将 Hugo 0.147.0 extended 放在 `.local/tools/`，无需额外安装。把项目复制到另一台电脑后，如没有 Hugo，可按 [Hugo 官方说明](https://gohugo.io/installation/) 安装。普通在线更新不需要在电脑安装任何工具。

## 把更新同步到在线网站

最方便的做法是直接在 [GitHub 仓库](https://github.com/nemochenyx/nemochenyx.github.io) 中打开对应文件，点击铅笔图标，修改文字，然后点击 **Commit changes**，提交到 `main` 分支。GitHub Actions 会自动生成并发布网页，通常需要几分钟。可以在仓库的 **Actions** 页面查看结果。

如果修改的是本地文件：本地保存会立即更新本地预览，但在线网站要在提交并推送到 GitHub 后更新。你可以使用 GitHub Desktop，或继续让 Codex 帮你同步。不设置自动后台上传，避免把尚未完成的文字误发出去。

GitHub 是在线版本的存档。每次更新后都能查看改动记录，必要时恢复之前的文字。如果先在 GitHub 上修改，再回到电脑修改，请先同步最新版本。

## 更新 CV

将新 PDF 替换到 `static/files/cv/YC_CV.pdf`，保持文件名不变。修改 `data/profile.yaml` 中的 `cv_date`，并更新 `content/cv/_index.md` 的网页简历文字。

PDF 和网页简历是两份独立内容：替换 PDF 不会自动重写网页简历，修改网页文字也不会改动 PDF。这样可以保留你正式排版的 CV。

## 更新照片

公开网页使用 `static/images/headshot.webp`。可以替换同名图片，或把新照片放在 `static/images/` 后，修改 `data/profile.yaml` 的 `photo` 路径。原始 PNG 保留在本地 `materials/images/`；网页版是等比例压缩副本。

## 添加论文

已发表论文加入 `content/publication/_index.md`。工作论文加入 `content/working-paper/_index.md`，按实际状态放在 Under Review 或 Work in Progress 下方。直接复制已有条目的格式：

```markdown
### 新论文标题

With **合作者姓名** (单位)  
*Under review*

这里写论文简介。

[Download paper (PDF)](/files/working-papers/new-paper.pdf)
```

若添加下载链接，先把对应 PDF 放到 `static/files/working-papers/`。已发表论文 PDF 放到 `static/files/publications/`。网页链接中的路径不含 `static`。没有 PDF 就省略下载链接。

论文发表后，将条目从 Working Paper 移到 Publication，并补充年份、期刊、卷期及 DOI。不要只改网页中的状态却忘记同步 CV。

## 文件分类

| 文件夹 | 用途 | 是否成为公开网页 |
| --- | --- | --- |
| `content/` | 四个页面的可编辑文字 | 生成对应网页 |
| `data/` | 全站共用资料 | 模板使用其中的公开字段 |
| `static/files/cv/` | 正式 CV PDF | 是 |
| `static/files/publications/` | 已发表论文 PDF | 是 |
| `static/files/working-papers/` | 工作论文 PDF | 是 |
| `static/images/` | 网站照片与图标 | 是 |
| `assets/css/` | 网站样式 | 编译成网页样式 |
| `layouts/` | 网页模板 | 生成网页 |
| `docs/` | 中文维护说明、参考资料、部署记录 | 不复制到网站；提交的说明会在公开仓库中可见 |
| `materials/` | 原始 CV 和照片，本地保存 | 不提交、不发布 |
| `.local/` | 本机 Hugo 程序 | 不提交、不发布 |
| `public/` | 自动生成的网页 | 由 GitHub Actions 发布，无需手动编辑 |
| `tmp/`、`docs/qa/` | 检查中间文件和截图 | 不提交、不发布 |

只把准备公开的 PDF 放进 `static/`；其中每个文件都会随网站一起发布。
