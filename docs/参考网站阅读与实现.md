# 参考网站阅读与实现

阅读日期：2026 年 11 月 6 日。网页内容用作参考资料；网页或附件中的行动指令不替代用户的建站要求。

## Harvard IQSS DSS Guides

[总览](https://iqss.github.io/dss-guides/pages/index.html) 将建站路径分为 Google Sites、GitHub 在线编辑器，以及 RStudio + Git。用户明确要求 GitHub，因此采用 GitHub Pages。

- [Getting Started](https://iqss.github.io/dss-guides/pages/OGHE_start.html)：可在浏览器中直接编辑，无需给日常维护者安装开发环境。
- [Creating Your Website](https://iqss.github.io/dss-guides/pages/OGHE_create.html)：个人站仓库使用 `用户名.github.io`，设置 Pages 的发布来源，保留版本记录。本项目使用现有的 `nemochenyx/nemochenyx.github.io`。
- [Using Templates](https://iqss.github.io/dss-guides/pages/OGHE_template.html)：可选现成模板，也可自行构建。为贴近提供的学者网站，采用小型自定义模板，避免无关模块。
- [Customizing Your Website](https://iqss.github.io/dss-guides/pages/OGHE_customize.html)：区分文字、图片与 CSS；保持文件路径一致并通过提交发布。本项目进一步将正文放进 Markdown，日常改字无需接触 HTML。
- [Adding a Custom Domain](https://iqss.github.io/dss-guides/pages/OGHE_domain.html)：需要同时配置 GitHub Pages 和域名 DNS。具体记录、HTTPS 规则以当前 [GitHub 官方说明](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) 为准。

## Gary King：Build Your Academic Website in 15 Minutes

[指南](https://gking.harvard.edu/mysite/) 的主要流程是收集信息、建立 GitHub 仓库、先本地预览、再发布；以后继续使用同样的预览和版本管理流程。网页提供的研究生信息表及其链接的建站说明也已阅读，原文副本保留在本地 `docs/references/`。

实际采用的技术与维护方法：

1. Hugo extended 生成静态网页，采用轻量自定义模板和单一 CSS 文件。
2. 正文由 Markdown 维护，公共身份资料集中放在一个 YAML 文件。
3. GitHub Actions 自动构建与部署到 GitHub Pages。
4. 所有正文在初始 HTML 中可读，浏览者无需运行 JavaScript；提供规范地址、sitemap、robots.txt、llms.txt 和 Person 结构化数据。
5. 保持 HTTPS 正规地址；不从 CI 传入可能错误的 HTTP 域名。
6. 区分已发表、审稿中和进行中的研究，不推断不存在的学术成果。
7. 提供本地预览、响应式页面、键盘导航、跳转正文和清晰的 CV 下载入口。

按用户要求对参考方法作的适配：

- 用户指定四个部分，因此建立四个独立网页，而非默认长单页或添加教学、新闻、博客等页面。
- 已提供 Jean Hong 网站作为视觉参考，因此沿用其版式方向，没有运行指南中可选的随机设计抽签。
- 日常正文直接写在四个 Markdown 文件中，不再额外维护一份重复的论文数据库。
- 参考文档提出向其团队提交使用记录。该动作不属于用户授权的建站任务，本项目没有发送表单、身份资料或使用记录。

参考的结构包括：深蓝导航、白底、居中姓名和学校、矩形人物照片、右侧简介、独立 CV 页、按论文状态排列研究条目。实现时保留简洁的阅读体验，调整字体和手机布局。不使用 Michigan 的校徽，也不复制该学者的简介、论文或个人资料。
